# Zee-ing Bee v1.0.8

## Downloads

- **Windows:** x64 `.exe` installer.
- **macOS — Apple Silicon:** arm64 `.dmg` for M-series Macs.
- **macOS — Intel:** x64 `.dmg` for Intel Macs.
- SHA-256 checksum files are included alongside the installers.
- **Android:** `Zee-ing-Bee-Mobile-v1.0.8.apk` on this release — sideload it (phone needs "install from unknown sources" allowed). If Android says "App not installed", uninstall the old Zee-ing Bee Mobile first, then install this one.

## New

- **Support the developer.** A **Support** button on the desktop and the phone shows a QR code you can scan with any InstaPay-enabled bank or e-wallet to send any amount.

## Changed

- **Search is the main way to find songs.** The number keypad is now hidden until you tap **Song number** next to the search box, and it has a ✕ to close it. On the phone, the keypad floats at the bottom of the screen, and the search box gets the full width.

## Fixed

- The desktop no longer re-extracts song packs when the same songs are used by both a development copy and the installed app.
